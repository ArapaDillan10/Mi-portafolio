# Notas de terminal - TP N°1
# Comandos

1. **pwd**  
   - *Qué hace:* Muestra la ruta del directorio actual.  
   - *Situación:* Lo usé para confirmar en qué carpeta estaba trabajando antes de crear o editar archivos de mi sitio web.  

2. **ls**  
   - *Qué hace:* Lista los archivos y carpetas dentro del directorio actual.  
   - *Situación:* Lo utilicé para verificar que mi archivo `index.html` y `style.css` estaban en la carpeta correcta.  

3. **cd**  
   - *Qué hace:* Cambia de directorio.  
   - *Situación:* Lo usé para moverme desde la carpeta principal hasta la carpeta donde guardé mi proyecto web.  

4. **mkdir**  
   - *Qué hace:* Crea un nuevo directorio.  
   - *Situación:* Lo usé para crear la carpeta `imagenes` donde guardé la foto que aparece en mi sitio.  

5. **touch**  
   - *Qué hace:* Crea un archivo vacío.  
   - *Situación:* Lo usé para crear el archivo `style.css` antes de empezar a escribir los estilos.  

6. **cat**  
   - *Qué hace:* Muestra el contenido de un archivo en la terminal.  
   - *Situación:* Lo usé para revisar rápidamente el contenido de `index.html` sin abrir el editor.  

7. **which git**  
   - *Qué hace:* Muestra la ruta donde está instalado Git en el sistema.  
   - *Situación:* Lo usé para cumplir con la consigna y verificar la instalación de Git.  

8. **code .**
   - *Qué hace:* Abre Visual Studio Code en el directorio actual.  
   - *Situación:* Lo usé para abrir mi proyecto completo y editar el código de manera más cómoda.  

9. **rm**  
   - *Qué hace:* Elimina archivos.  
   - *Situación:* Lo usé para borrar un archivo de prueba que había creado por error.  

10. **mv**  
   - *Qué hace:* Mueve o renombra archivos.  
   - *Situación:* Lo usé para cambiar el nombre de una imagen y que coincida con lo que puse en el código HTML.
