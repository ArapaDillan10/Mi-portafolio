# Reflexión
Aprender a usar la terminal es importante porque permite interactuar directamente con el sistema operativo sin depender de la interfaz gráfica. Esto brinda mayor control, rapidez y flexibilidad en tareas como la gestión de archivos o la instalación de programas. Además, el uso de la terminal ayuda a comprender mejor cómo funciona el sistema por dentro y es una herramienta fundamental para cualquier programador o administrador de sistemas.
